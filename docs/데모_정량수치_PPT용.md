## 1. 평가 지표 한눈에 (용어 — 슬라이드 각주용)

| 지표 | 뜻 | 범위/해석 |
|---|---|---|
| **hit@k** | 정답 청크가 검색 상위 **k개 안에** 들어왔나 | 비율(높을수록↑). 본 프로젝트 k=5 |
| **MRR** | 정답이 처음 등장한 **순위의 역수** 평균 (1위=1.0, 2위=0.5…) | 0~1, **1에 가까울수록** 정답이 위 |
| **top_k** | 최종 반환 근거 개수 (검색 파라미터) | =5 |
| **candidate_k** | 융합 전 후보 풀 크기 | =20 |
| **groundedScore** | 답이 **근거에 얼마나 충실**한지 (프론트 "정확도 %") | 0~1, verifier(o4-mini)가 채점 |
| **verdict** | 판정 = groundedScore를 **임계값으로 코드가 확정** | pass(≥0.7) / partial(≥0.4) / fail |

> 참고: "top-p"는 LLM **샘플링** 파라미터(다양성 조절)로, *검색 지표*가 아니다. "top-3"는 곧 **hit@3**(정답이 상위 3개 안). 검색 품질은 **hit@k·MRR**, 답변 품질은 **groundedScore·verdict**로 본다.

**표준 지표 지형 (RAG/에이전트 평가는 보통 4묶음)** — 우리가 무엇을 측정/미측정하는지 정직하게:

| 묶음 | 대표 지표 | 우리 | 비고 |
|---|---|---|---|
| **A. 검색 품질** | hit@k · **MRR** · (NDCG) | ✅ hit@1/3/5 · MRR | NDCG·RAGAS context recall은 미측정(2개사 데모엔 과함) |
| **B. 답변 품질** | **groundedness**(환각↓) · 정확도(exact-match) · answer relevance | ✅ groundedScore · verdict · 정확수치 일치 | RAGAS류 정밀지표 미도입 |
| **C. 회귀/커버리지** | pass rate | ✅ 골든 18/18 · 행동 9/9 · 검색 13/13 | CI로 매번 |
| **D. 운영** | latency · cost/token | △ 정성(질문당 ~$0.02–0.05) | 정밀 벤치 미실시 |

→ **A·B·C 충실, D 정성.** "검색(hit@k·MRR) + 답변(groundedness) + 회귀(pass rate)" 세 축을 갖춘 게 한 장 정량 성능의 표준 골격.

## 3. 답변 품질 — 이상적 질문 → 수치 결과 (시연 핵심)

대표 질문과 **실제 답에 나오는 수치 + 정확도(groundedScore/verdict)**. (정확 수치는 DART 정형 API가 결정적으로 책임)

| 질문 | 답변 핵심 수치 | 트랙 | groundedScore / verdict |
|---|---|---|---|
| 삼성전자 영업이익 알려줘 | 제57기 **43,601,051,000,000원** / 제56기 32,725,961,000,000원 | 재무결합 | **≈1.0 / pass** |
| 삼성전자 연간 매출액 얼마야? | 제57기 **333,605,938** / 제56기 300,870,903 (백만원) | 재무결합 | pass |
| 삼성전자 자산총계 얼마야? | **566,942,110** / 514,531,948 (백만원) | 재무결합 | pass |
| 2023년 삼성전자 영업이익 알려줘 | 제55기 **6,566,976,000,000원** *(요청 연도 정확 조회)* | 재무결합+기간 | pass |
| 제57기말 보통주 발행 주식총수는? | **5,919,637,922주** *(기수→사업연도 환산)* | corpus+기수 | pass |
| (현대) 연간 매출액 얼마야? | **175,231,153** (백만원) | 재무결합 | pass |
| 삼성전자 사업 내용 요약해줘 | DX·DS·SDC·Harman 부문 서술 (반도체·메모리·디스플레이) | 사전요약(하이브리드) | pass |
| 요즘 환율·금리 상황에서 실적 어때? | 공시 실적 + `macroSnapshot`(환율·기준금리·국고채·KOSPI) | 거시결합 | pass |

> groundedScore는 verifier(o4-mini) 채점값(소폭 변동 가능)이며, 정확 수치 답변은 관측상 ~1.0 → **verdict=pass**. 모든 답에 **출처 카드(접수번호·섹션·인용) + DART 원문 링크** 동반.
